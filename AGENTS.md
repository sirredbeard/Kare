# Agent instructions

Read these files in order before changing Kare:

1. [`README.md`](README.md) for the project, current setup, and human-facing workflow.
2. [`.github/copilot-instructions.md`](.github/copilot-instructions.md) for security, device operations, launcher behavior, coding constraints, and validation.
3. [`plan.md`](plan.md) for architecture, measured gates, open questions, and staged work.

Keep user setup and the project story in `README.md`. Keep operational detail, protected configuration, development rules, and agent guidance in `.github/copilot-instructions.md`. Keep research context and dated measurements in `plan.md` and `findings/`.

Do not commit credentials, host details, device addresses, usernames, provider deployment details, or copied GitHub Copilot settings.
